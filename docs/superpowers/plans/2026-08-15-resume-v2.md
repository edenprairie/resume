# Resume v2 (cv.junwang.us) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a brand-new, editorial-designed resume site for Jun Wang on Next.js 16 + TypeScript, deployed to GitHub Pages at `cv.junwang.us`, leaving the current site untouched.

**Architecture:** A new public repo `edenprairie/resume-v2` containing a Next.js 16 App Router app with static export (`output: 'export'`). The site is one scrollable page with a sticky nav (Experience · Projects · Skills · Education · Download PDF). All styling is hand-authored CSS with CSS custom properties (warm paper palette, serif display type, burnt-orange accent). Content is written from the existing resume's facts with strict anti-AI writing rules. A GitHub Actions workflow builds the app and deploys `out/` to GitHub Pages with CNAME `cv.junwang.us`.

**Tech Stack:** Next.js 16 (App Router), React 19.2, TypeScript, CSS custom properties, `next/font/google` (Source Serif 4), Vitest + React Testing Library (content tests only), GitHub Actions + peaceiris/actions-gh-pages.

**Work location note:** The new site is its own repo. Scaffold it in a scratch directory (e.g., `/tmp/resume-v2`), push to GitHub, and keep the current `resume` repo untouched.
